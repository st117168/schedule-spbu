## Что делает

- Скачивает Excel-файл с расписанием с сайта `timetable.spbu.ru`.
  Чтобы получить русскую версию, скрипт отправляет заголовок
  `Accept-Language: ru`. Без этого заголовка сайт отдаёт английскую версию.
- Фильтрует занятия по подстрокам, заданным в `config.json`.
- Выводит расписание в консоль в виде двухколоночной таблицы:
  **пн–ср** (левая колонка) и **чт–сб** (правая).
- Показывает номер пары (`1)`, `2)`, `3)` …) в зависимости от времени начала.
  При пропуске пары нумерация перескакивает (например, 1, 3, 5).
- Сохраняет расписание в **PNG** с цветными плашками:
  дни недели — тёмно-красные, время — серые.
- Поддерживает просмотр **текущей** (по умолчанию) и **следующей** недели.
- Кэширует скачанные файлы в папке `cache/`, чтобы не скачивать повторно.

## Что нужно для запуска

- Python 3.10 или новее
- Библиотеки:

```bash
pip install pandas openpyxl requests pillow
```

- Файл `config.json` в той же папке, что и скрипт:

```json
{
    "student_group_id": 460028,
    "subject_filters": [
        "Физика",
        "Уравнения математической физики",
        "Методы вычислений",
        "Машинное обучение",
        "Механика деформируемого твердого тела",
        "Гидроупругость",
        "Устойчивость и управление движением"
    ]
}
```

- `student_group_id` — ID группы (виден в ссылке на расписание).
- `subject_filters` — список подстрок. Занятие попадает в вывод,
  если его название содержит хотя бы одну из них (регистр не важен).
  Названия предметов в скачанном файле — **на русском языке**,
  поэтому и фильтры должны быть на русском.

## Как запустить

```bash
# Текущая неделя (по умолчанию)
python spbu_schedule.py

# Следующая неделя
python spbu_schedule.py --week next

# Не скачивать заново, использовать последний файл из cache/
python spbu_schedule.py --no-download

# Указать другой файл конфигурации
python spbu_schedule.py --config my_config.json
```

После запуска:
- в консоль выводится расписание;
- рядом со скриптом сохраняется PNG вида
  `расписание_2026-09-14_текущая.png`.

## Структура проекта

```
spbu_schedule/
├── config.json           # ID группы и фильтры предметов
├── spbu_schedule.py      # основной скрипт
└── cache/                # скачанные Excel-файлы (создаётся автоматически)
```

## Настройка

- **Фильтры предметов** — в `config.json`, поле `subject_filters`
  (подстроки на русском языке).
- **Номера пар** — в словаре `SLOT_NUMBERS` в скрипте
  (соответствие времени начала и номера пары).
- **Цвета плашек** — константы `DARK_RED` и `GRAY`
  в функции `save_schedule_as_image`.
- **Размер шрифта и отступы** — параметры `font_size` и `padding`
  в `save_schedule_as_image`.
